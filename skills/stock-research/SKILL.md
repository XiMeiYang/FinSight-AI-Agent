# stock-research

当前为流程规范；数据、工具与运行环境尚未接入。执行时遵守仓库 [AGENTS.md](../../AGENTS.md)，不能把规划当作已完成的操作。

## 输入

证券唯一身份、用户问题、分析截止时间及可用数据来源。代码歧义时先消歧；缺少来源时列出所需材料，不声称已经查询。

## 工作流程

1. 阅读 [PRD](../../docs/04-prd.md) 与 [数据源方案](../../docs/06-data-sources.md)，核对范围和时间口径。
2. 先识别意图、证券和时间范围并读取必要会话上下文；按任务复杂度调用暂定的行情、基本面、新闻事件、行业与宏观等角色，综合研究覆盖行情、技术面、基本面、新闻情绪、行业、宏观和风险，简单请求不强制全部角色；如需文档检索，按 [financial-rag](../financial-rag/SKILL.md) 组织证据包。
3. 在 Point-in-Time 约束下使用历史相似事件验证当前假设，匹配特征及用于验证的结果须在截止时间已公开可用；缺少样本时明确不足。对需要综合判断的任务，基于同一截止时间形成多头、空头独立初稿并互相质疑，分别给出支持证据、反证和失效条件；不可把同一观点换措辞冒充独立分析。
4. 证据审计检查来源、时间顺序、推理链与替代解释，特别防止把晚于价格变动的新闻当成原因；风控检查缺失、过期、集中风险、流动性和事件不确定性；裁判回应分歧并说明采纳依据。关键证据不足时弃权。
5. 报告阶段按请求汇总实际分析与适用图表，综合研究覆盖七维及 K线、财务、新闻情绪和行业对比；保存每次判断和证据，供复盘 Agent 在 5/20 个交易日后评估。数值通过可复现计算核对，保留工具与模型版本。如未具备实际多 Agent 运行条件，只输出流程草案或明确标注的角色分析，不声称已完成多个 Agent 调用。

## 输出与边界

输出证券、截止时间、来源、任务要求的分析与依据；综合研究另含相似事件、多空观点、风控、裁判、未解决分歧和缺失项，不为简单查询虚构未调用角色的结果。区分事实与推断，引用定位到原始证据。无真实券商接入、无真实交易，不承诺收益。依赖未就绪时标注阻塞或部分完成，不编造实时分析结果。

## 职责与停止条件

本 Skill 负责单股研究；股票对比由任务路由组织各股票研究后汇总，不将本 Skill 扩大为通用任务规划器。需要计算时调用 Python、SQL 或确定性工具，记录计算依据；缺少工具就标记未计算，不能心算补数。

输出包含置信度依据与能力限制，不提供确定性投资建议。证券歧义或关键时间未明确时先澄清相关部分；关键证据、权限或计算条件缺失时停止确定结论并返回缺口。复杂角色定义见技术方案，不声称每次都已调用全部 Agent。
