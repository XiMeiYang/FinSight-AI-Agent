# agent-evaluation

当前为流程规范；数据、工具与运行环境尚未接入。执行时遵守仓库 [AGENTS.md](../../AGENTS.md)，不能把规划当作已完成的操作。

## 输入

评测模式、样本与版本、原始报告、证据截止时间、运行配置及评价规则。历史复盘使用已确认的 5/20 个交易日周期，另需明确起算点、价格锚点、基准、复权方法和到期时间。

## 工作流程

1. 阅读 [评测方案](../../docs/07-evaluation.md)，区分离线质量评测与产品历史复盘；不混合报告其结果。
2. 离线评测覆盖实际启用的 Agent、意图与路由、工具选择和计算、建议检索链路的实际配置、历史相似事件、可视化与 LLMOps 轨迹；固定样本和模型/提示版本，验证引用支持、数值、时间泄漏、多空独立性、风控约束、裁判分歧处理及安全边界。
3. 至少比较人工收集与报告（Baseline A）、单次大模型直接分析（Baseline B）和 FinSight 系统（Experiment）；按评测方案使用相同任务、截止时间与评价标准，披露不同资源和实际成本，报告样本量、失败案例及费用差异；合成与真实样本分开统计。
4. 历史复盘保持原报告不可变，只使用已到期且可核验的价格区间；按确定口径计算观察收益及基准差值，解释原观点是否满足其可验证条件。
5. 依保存的判断及复盘按 Agent、事件类型、数据源统计历史表现，披露各组样本量、分母、时间窗口、归因口径与限制，避免重复计数。原报告没有明确方向预测时不强算命中率；停牌、退市、未到期或缺失数据保留在样本状态中，不删去不利样本。

## 输出与边界

输出运行 ID、模式、样本与配置版本、实际执行步骤、指标及分母、失败案例、局限和改进建议。没有执行工具或有效样本时只输出计划，结果标记“未执行”。不编造准确率、延迟、成本或收益；观察收益不等于真实交易收益。依赖或口径缺失时列明阻塞项，不偷偷选择有利口径。

## 职责与停止条件

按 [评测方案](../../docs/07-evaluation.md) 执行数据/工具、RAG、Agent、产品和 LLMOps 指标，不在 Skill 内复制指标或 Schema。复盘分别检查事实、事件、归因、风险和方向，以及置信度与真实表现的关系，不以股票上涨作为唯一正确标准。

缺少可核验样本、必要工具或评分口径时停止指标计算，输出未执行及阻塞项；禁止补造调研、答卷、基线或百分比。事件研究可用 1/5/20 个交易日窗口，产品自动复盘仍为 5/20 个交易日。此 Skill 不负责生成当前投资判断或发送日报。
