# daily-report

当前为流程规范；数据、工具与运行环境尚未接入。执行时遵守仓库 [AGENTS.md](../../AGENTS.md)，不能把规划当作已完成的操作。

## 输入

用户自选股及每股关注方向、两类阈值和报告频率的配置快照、交易日期、交易日历、证据截止时间、研究结果、通知偏好和投递授权。读取 [PRD](../../docs/04-prd.md) 的报告与通知要求。

## 工作流程

1. 按每日收盘生成完整报告的确定要求执行；日报/周报选择与每日收盘生成、投递的关系未明确时列为待定，不擅自取消每日报告。确认目标交易日已收盘，考虑提前收盘和夏令时；未收盘时不得标为正式收盘报告。
2. 核对自选股覆盖与数据新鲜度，按需要使用 [stock-research](../stock-research/SKILL.md) 的分析结构，不编造缺失股票的结论。
3. 报告 Agent 汇总行情、技术面、基本面、新闻情绪、行业、宏观与风险分析、多空分歧、历史相似事件及后续关注点，并包含 K线、财务、新闻情绪和行业对比可视化；每个金融结论关联数据与来源；报告开头披露数据截止时间与缺口。
4. 按用户、交易日和版本生成唯一报告记录，保存证据与版本；更新形成新版本，不覆盖原始报告。
5. 按已确认的 5/20 个交易日周期登记复盘任务；起算点或调度能力未就绪时明确未登记原因，不假装已安排。
6. 仅通过已配置且获授权的渠道发送，并记录独立投递状态；有限重试与幂等去重，不能把供应商接收描述为用户已读。

## 输出与失败处理

输出报告 ID、日期、自选股覆盖、数据状态、逐股分析、综合风险、引用和归档/投递状态。部分缺失可形成明确标记的部分报告；未具备存储、调度或邮件能力时返回草稿与未执行清单，不宣称已保存、已安排或已发送。

## 职责与停止条件

最低内容按 [PRD 报告要求](../../docs/04-prd.md) 检查，包含整体和逐股表现、量价异常、行业大盘、新闻公告、基本面变化、正反观点、风险、判断、观察指标、时间来源及限制。保存每次判断、正反证据、置信度和模型/工具/数据版本。

收盘后仍须等待或检查允许延迟的数据是否到齐，未齐则标记部分报告。仅负责日报汇总、归档和授权投递，不重复承担监控或评测；周报方案另行明确。没有授权收件人时停止发送，没有存储或任务工具时返回未执行状态。
