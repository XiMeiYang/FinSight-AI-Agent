# 竞品分析框架

状态：待调研。本次未访问竞品网站或验证产品能力、价格与 API；下表为调研对象类别及问题，不是市场事实或竞品评分。

## 比较范围

| 候选类别 | 要验证的能力 | 本项目对照需求 |
| --- | --- | --- |
| 行情与图表工具 | 股票搜索、分钟级数据、异动告警及许可 | 搜索与监测 |
| 财经资讯与研究平台 | 公告覆盖、新闻时效、引用与历史访问 | 金融 RAG |
| 通用大模型研究助手 | 数据截止时间、来源引用、重复运行一致性 | 即时研究与真实性 |
| AI 投研或多 Agent 项目 | 多空分歧、风控阻断、评测可复现性 | 协作机制与评测 |
| 自选股及报告工具 | 收盘汇总、通知渠道、历史复盘 | 日报与 5/20 个交易日复盘 |

## 统一调研记录

每个实际候选记录：名称、官方链接、核验日期、版本或套餐、目标用户、市场覆盖、延迟、研究能力、引用质量、告警、日报、历史复盘、导出权限、价格依据和限制。用“官方明确支持 / 实测通过 / 不支持 / 未知”区分证据状态，不能把未知写成不支持。

采用同一只股票、相同数据截止时间和同一问题进行可复现比较。保留页面证据或合法测试记录，注明试用限制；不绕过付费墙，不虚构测试账户与运行结果。

## 待验证的差异化假设

本项目拟把可溯源研究、多空论证、风险审查、持续监控和事后复盘连接起来。这是否构成优势需与真实竞品对照，不能预先声称市场唯一或优于现有方案。

下一步由目标用户、预算和市场范围筛选具体候选，再开展有来源的调研并更新此文档。

## 与已确认背景对齐的比较维度

针对缺少每日研究时间的美股个人投资者与金融学习者，补充比较：七维分析覆盖、逐股关注方向和阈值及报告频率、K线/财务/新闻情绪/行业对比可视化、历史相似事件、Point-in-Time、每个金融结论的证据链、判断保存与 5/20 个交易日复盘，以及按 Agent/事件类型/数据源统计历史表现。免费行情的分钟级延迟与高频实时能力分开记录，不能按本项目未要求的高频标准判定不合格。

项目的六项创新方向已确定，比较优势仍待证据验证。竞品分析在实施流程中位于用户验证之后、正式用户访谈之前；当前未执行调研。

## 新背景补充与结论边界

将股票对比、财报/历史报告问答、意图路由、多轮记忆、反证及错误归因检查、用户可配置日报/周报、5–15 分钟延迟模式纳入同口径比较。“现有工具只提供行情、新闻或泛泛总结”是待验证痛点，不是本项目已证实的竞品结论。

TradingAgents 仅作为用户提到的潜在开源参考，尚未阅读或测试，不预填其功能、局限或优劣。项目不能复制开源项目充当独立成果；未来调研记录借鉴、许可与自身贡献。本次不访问外部产品或 API。
