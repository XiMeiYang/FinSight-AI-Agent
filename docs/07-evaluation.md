# 评测与自动复盘方案

状态：计划，未执行实验，没有准确率、性能或收益结果。下列指标均未设最终门槛。

## 评测集合

建立有版本的离线样本，覆盖信息充分、缺失、过期、相互矛盾、财报修订、股票改名、停牌、拆股分红、休市、提前收盘和提示注入。每项保留来源与时间；合成异常与真实历史样本分开统计。开发集与最终评测集按时间划分，避免重复文档泄漏。

## 5/20 个交易日复盘

自动复盘是产品功能；它不同于离线 Agent 评测，也不是实际交易收益。已确认采用 5 个交易日和 20 个交易日，起算时点、价格锚点和基准仍待确认。

原报告生成时保存不可变观点、证据截止时间、明确的预测期限和可验证条件；没有方向性预测的报告只评估证据与事件变化，不强行计算命中率。锚点建议使用报告可获取后首个可交易时点的价格，具体价格类型待确认，避免使用用户当时无法获得的成交价。

到期后使用一致币种与复权口径计算观察收益 P_h / P_0 - 1，以及相同区间的基准收益和两者差值。该差值是简单超额观察收益，不等于策略收益；不能忽略交易成本后声称可实现盈利。

保留原始快照，另建复盘记录；停牌、退市、缺失价格或尚未到期时展示原因与状态，不丢弃不利样本或捏造终值。更正数据产生新复盘版本，并注明修订原因。

## 已确认创新对应的评测补充

- 每个金融结论关联数据和来源：逐条核查判断到证据的连接及支持关系，模型推断也须有依据；不仅抽查数值。
- 多空交叉辩论：检查是否实质回应对方质疑，是否存在未经证据支持的裁判结论。
- 历史相似事件：记录匹配规则、事件类型、样本量、支持与反例；无相似样本时报告不足。匹配输入和已知结果均接受 Point-in-Time 检查。
- 建议 RAG 链路：评估解析、分块、BM25、Embedding、RRF、Cross-Encoder 重排、截止时间过滤、证据提取及引用核验；通过对照实验决定具体实现，不预设组件收益，不能取消时间与真实性要求。
- 可视化：核对 K线、财务、情绪及行业对比是否与数据、单位、时间和来源一致。
- LLMOps：检查各 Agent、检索与工具调用轨迹是否完整，失败、成本和耗时是否真实可追溯。

## 按 Agent、事件类型和数据源统计历史表现

该统计能力已确定。建议从保存的判断、引用和复盘中建立关联，按三类维度分别及交叉汇总样本量、证据支持、数值正确、到期情况和可定义的预测表现。不同 Agent 使用符合职责的评价，不强迫报告 Agent 等角色产生方向性预测。

每组展示指标定义、分母、时间窗口、缺失与失败样本和不确定性；小样本不直接排名。多来源共同支撑的判断记录归因方法，避免重复计数或将相关性解释为单一来源贡献。当前没有任何统计结果。

## 多维复盘与置信度

每次报告登记当时可获取的数据、主要判断、正反证据、置信度、风险、生成时间、数据截止时间、模型/工具/来源版本。5/20 个交易日后分别评估事实准确性、事件识别、原因归因、风险识别和方向判断，不能仅因股价上涨判为正确。

检查风险提醒是否发生、事件类型差异、高置信度判断是否更可靠、哪个 Agent 易出错、哪些来源更可靠。置信度定义与校准方法待定，未校准不得展示为真实概率；高置信度分组的表现必须有样本量及失败案例。

## 历史相似事件研究

针对财报超预期、指引下调、高管变动、回购、监管事件等，计算 1/5/20 个交易日收益、超额收益、波动率变化、成交量变化和正收益比例。1 个交易日是事件研究观察窗口，不替代产品固定的 5/20 个交易日复盘。

指标的价格锚点、基准、复权、波动率和成交量窗口、事件匹配规则待确认。只使用截止时点已知且观察窗口已成熟的历史结果验证当前假设；记录缺失、退市、重叠事件和样本选择偏差，避免只挑支持案例。相似事件统计不构成确定性投资建议。
