# 用户访谈综合分析 001

状态：已完成小样本定性访谈，结论用于调整验证顺序与 MVP 交互，不代表市场比例、普遍需求或产品效果。

## 1. 研究目的

了解目标用户最近的美股研究流程、信息核查困难、告警与报告偏好，为原型验证和 MVP 优先级提供初步证据。

## 2. 样本和方法

- 样本量为 3，均为真实访谈；通过朋友转介和相关学习社群招募。
- 访谈采用线上语音方式。
- 模拟访谈不计入真实样本，仅作为设计参考。
- 小样本只能形成初步定性证据，不能推断市场比例。

## 3. 隐私与证据边界

完整访谈记录、联系方式、录音和未脱敏材料未进入仓库。本文不记录精确日期、职业或学校、公司、持仓、课程、群聊信息、直接引语或可组合识别个人的细节。本文只保存匿名聚合观察，不计算满意度、效果提升或付费比例。

## 4. 跨参与者共同发现

- 研究时需要在行情、公告、新闻和解释材料之间切换，来源整理本身造成负担。
- 找到财务数字后，仍需要核对原文、时间和口径；可定位引用比单纯摘要更重要。
- 用户希望先看到简短结论，再按需展开证据和限制。
- 对自动投资结论保持谨慎，希望保留自行判断空间。

## 5. 用户需求分化

暂时形成两个行为分层，不能视为完整市场画像，也不是互斥人群；同一用户可能同时属于两类：

1. **证据驱动研究型**：关注财报定位、指标口径、引用、时间线和 Excel 导出；对分钟提醒和自动日报需求较弱。
2. **持续跟踪监测型**：关注价格与成交量异动、旧闻识别、提醒降噪和收盘总结；对财报深度分析的使用频率可能较低。

## 6. 支持的痛点假设

在本次样本中，以下假设获得初步支持：信息分散和跨工具核对、财报关键内容定位、财务指标口径核验、引用与原文追溯、新闻/公告/行情时间审计、异动发现，以及告警噪音控制。支持仅限于访谈描述，不等于已验证市场需求。

## 7. 出现反证或分化的假设

以下假设出现分化或反证：所有用户都需要分钟级监测；所有用户都需要每日邮件；自动生成报告等于自动发送报告；用户希望查看复杂多 Agent 过程；用户只需要更多信息。方向上更需要摘要、证据、风险和可关闭的提醒，不能据此宣称统一偏好。

## 8. 信息不足的问题

仍缺少付费意愿、告警频率和延迟阈值、邮件打开和使用情况、财报 RAG 的真实准确率、用户是否实际点击并核对引用，以及学生与个人投资者之间的需求差异证据。

## 9. 对产品优先级的影响

首个可验证闭环调整为：用户输入 `NVDA` → 获取已保存的日线行情 → 获取 SEC 财报和公告 → 展示基础行情与关键财务信息 → 每个数字显示时间、单位和来源 → 生成简短摘要与可展开证据 → 导出 Excel → 保存运行记录。

新闻时间线暂时只定义接口和页面位置，不能冒充已接入新闻数据；财报 RAG、多 Agent 尚未实现；系统不提供投资建议。Excel 导出作为围绕已保存快照的 P0 验证输出，分钟级监测、成交量异常、旧闻识别、告警合并与冷却、自选股持续监测、条件式邮件和 5/20 交易日复盘调整到 P1。MVP 冻结仍需根据后续原型测试调整。

## 10. 下一轮验证计划

下一轮使用当前可点击原型验证上述闭环：搜索并分析 NVDA、找到结论来源、理解摘要展开和数据状态、查看多空分歧占位、加入自选股、查看收盘报告并打开 Excel 导出预览。记录任务完成情况、误解和证据定位行为，继续匿名化；执行前不填写成功率、满意度或效果指标。
