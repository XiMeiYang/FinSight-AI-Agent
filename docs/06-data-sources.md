# 数据源方案

状态：免费或低成本与 5–15 分钟延迟容忍已确认；具体来源为优先候选，最终选择须真实 API 测试后冻结，接口能力、许可和套餐未核验，尚未接入生产数据流程。不提供未经验证的 API 地址、参数、价格或额度。

## 数据需求

| 数据 | 用途 | 核验重点 |
| --- | --- | --- |
| 证券主数据 | 搜索、消歧、自选股 | 交易所、类型、改名与退市历史 |
| 分钟行情与成交量 | 异动监控、分析 | 源延迟、时间戳语义、许可、缺口与限流 |
| 日线和公司行动 | 趋势、5/20 个交易日复盘 | 分红拆股、复权版本、退市数据 |
| 财报与公司公告 | 基本面 RAG | 原始出处、公开时间、修订版本与可定位引用 |
| 新闻与事件 | 事件解释 | 发布时间、采集时间、版权、重复与更正 |
| 交易日历 | 监控、收盘与复盘 | 节假日、提前收盘、夏令时和会话范围 |
| 宏观数据 | 行业与宏观分析 | 公开时间、历史版本、后续修订与 Point-in-Time |
| 行业分类与可比公司 | 行业对比及可视化 | 分类版本、样本选择、指标口径与来源 |
| 历史事件 | 相似事件验证与表现统计 | 事件类型、可用时间、结果观察窗口与选择偏差 |
| 基准序列 | 复盘对照 | 与股票收益的日期、币种和复权口径一致 |

## 候选来源与优先顺序：尚未冻结

| 数据 | 优先候选 | 尚未完成的实施核验 |

| 美股行情 | Alpha Vantage、Finnhub、Financial Modeling Prep、Massive 或其他合法供应商 | 最终供应商、证券覆盖、延迟、额度、价格和许可 |

免费或低成本行情允许存在 5–15 分钟延迟，不追求高频交易级实时性。这是正常允许的产品模式，不应自动标记为故障；必须显示数据时间、来源与延迟。分钟级采集频率和源数据延迟分别验收，MVP 只监控美股正常交易时段，暂不含盘前盘后。

行业分类与可比公司、证券主数据、交易日历和基准的具体来源尚待选择。所有候选不代表官方能力、许可或可用性已验证，不能预填免费额度或性能。不得将网页爬虫作为唯一核心数据源。

每个候选建立证据卡：官方文档链接、核验日期、覆盖证券、免费额度、数据延迟、支持时间粒度、历史数据长度、认证方式、调用次数限制、费用、缓存许可、再分发和项目展示许可、修订策略、故障支持。许可或延迟不满足要求的来源不能进入对应生产路径。

## 数据质量与溯源

统一保存原始证券标识、映射版本、UTC 时间、源时区、币种、单位和供应商状态。区分事件发生、公开发布、首次可获取、采集及分析截止时间。用于历史评测的可用时间证据不足时，不能声称严格的历史时点评测。

检查重复、乱序、异常值、缺失区间、复权差异和过期数据。不同来源冲突时保留双方及裁决依据，不能静默合并。行情指标通过可复现程序计算，公式和窗口需要版本化。

## 分阶段接入

### SEC EDGAR / Company Facts 离线 PoC

仓库已提供标准库 SEC 适配器，覆盖 ticker→CIK、Submissions 申报筛选、归档 URL、Company Facts 规范化、`as_of` 过滤和原始响应 SHA-256。raw 与 normalized 分离，保留来源、时间、表单、accession number、单位和定位 URL。固定 synthetic fixture 仅用于离线验证，不代表 SEC 在线接口、额度、许可或生产数据质量已验证。

官方资料核验（2026-09-21）：[EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)；[Accessing EDGAR Data](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)；[SEC rate control](https://www.sec.gov/filergroup/announcements-old/new-rate-control-limits)。本 PoC 的 company tickers 使用 `https://www.sec.gov/files/company_tickers.json`，Submissions 使用 `https://data.sec.gov/submissions/CIK##########.json`，Company Facts 使用 `https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json`；代码生成的 filing URL 使用 SEC Archives 前缀，但该路径不是本核验链接。Company Facts 的 XBRL 边界、10 req/s 公平访问、User-Agent 和 CORS 限制均已记录；一次 NVDA smoke 已执行，生产接入仍未完成。

网络访问由 `FINSIGHT_SEC_USER_AGENT` 显式控制；未设置时拒绝请求。429/5xx 在有限预算内重试，超时、网络错误、4xx 和无效 JSON 返回结构化错误。PoC 不安装依赖、不连接数据库、不启动任务。

先使用明确标记的 synthetic 样例测试边界，或使用许可允许且保留来源的历史样本；样例结果不得宣称真实有效。用户启动后续接入阶段后，再完成官方资料核验、许可及预算确认、凭证配置和小规模契约测试。只有实测过的数据质量和延迟才能标为已验证；供应商最终选择必须在真实 API 测试后才能冻结。根据实测额度再决定每用户自选股上限，不能现在写死数量。

## 降级与安全

来源不可用时显示中断、过期或部分数据，不伪造数值。分钟级监控分别检查采集频率与已配置的允许延迟；免费分钟级延迟在允许范围内可正常用于分析和监测，超出允许上限或缺少关键数据时才降级。敏感凭证不入库、不入日志；许可不允许保留全文时，仅按授权保留必要引用与定位信息。

## 更新、K线与导出数据契约

行情采集频率、源延迟和检测周期分别记录；正常交易时段内允许的 5–15 分钟延迟不自动判为故障。公司行动、财报更正和宏观修订采用追加版本，不能覆盖原始时点记录。每次报告、图表和导出都绑定数据版本与 `as_of` 截止时间。

K线接口应返回 OHLCV、`event_time`、来源、币种、单位、复权口径、延迟/freshness 和缺失区间。Excel 导出只允许读取已保存的事实、计算、证据和报告快照；每列保留来源、事件/公开/采集时间、币种、单位、数据版本及缺失/冲突说明。LLM 不得临时生成或补写行情、财务数字。接口路径和供应商均待验证，当前未连接服务。

## Point-in-Time 数据要求

历史分析与回测只能使用当时已公开且可获取的信息。SEC EDGAR 财报与公告、FRED 宏观序列及其他来源均须区分原发布版本与后续修订版本，不能用今天下载的最新值直接冒充历史时点数据。若无法获得可验证的当时版本，应明确评测限制或阻断该历史样本。

保存每次判断与其证据来源、事件类型和 Agent 关联，用于 5/20 个交易日复盘及分组表现统计。历史相似事件的匹配特征与用于验证的结果必须在当前分析截止时间可用，避免通过事件标签或结果引入未来信息。

## 所有数据的溯源字段

以下为内部数据规范，不是声称外部 API 具有这些字段：source（来源）、event_time（事件时间）、published_at（公开时间）、retrieved_at（抓取时间）、freshness（新鲜度）。另保留行情时间、数据版本、原始文件位置、首次可用时间及分析截止时间。

对某类数据不适用或无法取得的字段显式记录空值原因，不能用抓取时间伪装公开时间；freshness 的计算参考时点与延迟说明必须可复核。研究历史时点时缺少必要时间依据须阻断或披露限制。

## RAG 材料范围

包含 10-K 年报、10-Q 季报、8-K 重大事项公告、财报电话会文本、投资者关系材料、金融指标解释、历史研究报告及系统历史分析。各类来源与许可独立核验，不宣称 SEC 提供所有材料。数字必须能定位到原始文件、日期、页码/章节/表格；系统报告保留原引用与版本，不作为独立原始证据。
