## 五例的归因

| 项目 | 原始记录直接显示的现象 | 本轮代理复核意见 |
| --- | --- | --- |
| D002（时间） | 模型理由写的是较早报告日期，却把主张中的另一日期判为 `supported`；摘录来自窗口 | 窗口**缺少**主张日期的数据，但没有明确否定该日期也可能有同一数值。原参考标签 `contradicted` 建议改为 `unsupported`，模型的支持判定仍属错误放行 |
| D003（数量） | 窗口和模型理由均是少数，模型却支持“大量”；摘录来自窗口 | 同一数量关系明确相反，原 `contradicted` 标签保持 |
| D004（摘录） | 模型在摘录中拼接省略号；仅折叠空白后仍不是窗口连续子串 | 确定性 `validation_failed` 正确。主张本身有窗口依据，不能把校验失败算作已接受的语义拒绝 |
| D008（对象） | 模型理由承认窗口未提到主张对象，却判 `supported` | 没提及不等于明确否定，原 `unsupported` 标签保持 |
| D012（单位） | 入模窗口在净收入行前给出金额单位，模型摘录略去单位并判 `supported` | 净收入行与单位在同一窗口且相邻；主张单位与窗口相反，原 `contradicted` 标签保持。窗口缺期间列标题，不能外推出具体期间 |
