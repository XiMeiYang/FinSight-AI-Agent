# 离线 Evidence Auditor 最小 PoC

## 范围与运行

2026-10-27，在代码基线 `68608571faeda4c192a81636329b22c5cef01c78` 上增加独立的“主张—单条引用窗口”审计实验。输入必须先由人或其他流程拆成独立检查项；每项有唯一 `pair_id`、主张、原引用 E 编号、**实际入模**的英文窗口和 filing 来源。模块不拆分整份回答，不检索其他窗口或完整申报文件，不接入网页、默认回答路径，也不修改原回答。当前默认生成提示词未改。

服务端要求结果与输入 ID 一一对应，判定只能是 `supported`、`partially_supported`、`unsupported`、`contradicted`、`uncertain`；支持、部分支持及矛盾判定必须附非空英文摘录。摘录只允许折叠空白后与**该检查项自己的窗口**匹配，来源身份由服务端回填。字符串校验只证明摘录出现在窗口中，**不证明语义上支持主张**。缺少提及不等于证据相反。非法 JSON、未知/重复 ID、伪造摘录、超时和截断均明确失败，不重试。主张和证据中的指令均视为不可信文本。

默认命令只准备请求，`model_calls=0`；真实本地调用需要显式 `--run-model`。下面的路径只是本机示例，完整真实样本不随 Git 分发：

```bash
PYTHONPATH=src python3 scripts/run_evidence_auditor.py \
  .local_data/reviews/nvda-evidence-auditor-2026-10-27-001/batch-1.json \
  --output-dir .local_data/reviews/nvda-evidence-auditor-2026-10-27-001/prepared-1
```

本次两批各四项已在运行前冻结。`--run-model` 会经既有 `OllamaClient` 访问本机 `127.0.0.1:11434`，不得把它理解为 SEC 联网。完整请求、模型原始响应、校验结果、源窗口、既有初审标签及哈希分别保存在 Git 忽略目录 `.local_data/reviews/nvda-evidence-auditor-2026-10-27-001/`；参考标签未进入模型请求。可用本地 `summarize_run.py` 从已保存记录重算对照和计数，且不再调用模型。

第 1 批有一条输出借用了**另一检查项**的英文摘录，服务端检测到摘录不属于本窗口，整批拒绝。另有一条在本窗口找到原文，却将“产能可用性”误判为“组件可用性”：词面校验没有发现这个语义错误。第 2 批通过结构校验，但一条把具体供给风险概括为整个供应链的不确定性，现有初审仅认为部分支持。其余项包括直接支持和不支持的正确示例。完整八项逐条标签、主张、窗口和模型理由只在本地对照表中，不进入仓库。
