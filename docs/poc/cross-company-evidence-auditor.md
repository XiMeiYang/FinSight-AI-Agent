# 跨公司 Evidence Auditor 小型诊断

状态：2026-10-27 完成一次本地诊断；**Codex 预标注与初审，待用户人工复核**。这不是生产功能、人工 gold、真实用户问题集合或最终独立测试集。

## 方法和冻结边界

在代码基线 `eaa62fa646ed29cacda1a32f82c9205760f26401` 上，复用现有逐对隔离审计器。仅从本机已保存且经现有 corpus 加载器校验的 AMD、AVGO、INTC、QCOM SEC 正文取证；每家公司选两个不同 filing，共八个真实英文证据窗口。每个窗口配一条直接支持主张和一条只改变关键条件的构造主张，共 16 条。构造主张并非实际用户提问或自然生成的错误。两个主张共享同一窗口，因此 16 项并非 16 个独立来源。原文窗口由现有 `make_evidence_excerpt` 产生，未扩充字符预算；保留了 accession、chunk、filing 日期、SEC URL、相对本地定位与文件哈希。争议候选在模型调用前剔除，修正及理由也在模型调用前留存。

参考判定先由独立只读代理在未看模型结果的情况下核对，最终冻结为 8 条 `supported`、7 条 `contradicted`、1 条 `unsupported`。这里的 `unsupported` 表示窗口没有足够依据，不能偷换成“原文明确否认”。参考标签、理由与输入分别保存。中性 ID 和固定随机种子 `271027` 确定顺序；提示词、JSON Schema、校验规则、模型 `qwen3:4b` 与已安装 digest 均沿用原版本。每次请求仅含当前主张和当前英文窗口，不含标签、构造方式、其他样本或历史回答。

盲审 PASS 先通过本任务会话消息返回，随后才执行模型命令；当时**没有单独落盘盲审报告或精确完成时间**。现将原 PASS 消息和审阅者事后复述另存为本地 `independent-preflight-transcript.md`，明确标注为运行后转录，不能冒充运行前生成的文件。冻结输入与参考标签的 SHA 在运行前 manifest 中保存；该时间留存缺口应在后续正式评测流程中补上。

可复制的**离线准备命令**（需本机保留的 Git 忽略输入；不会调用模型）：

```bash
PYTHONPATH=src python3 scripts/run_evidence_auditor.py \
  .local_data/reviews/sec-evidence-auditor-crossco-2026-10-27-001/input.json \
  --output-dir .local_data/reviews/sec-evidence-auditor-crossco-2026-10-27-001/prepared
```

本次已授权的显式 `--run-model` 模式按冻结顺序逐项运行，最多 16 次 `/api/chat`，没有重试；再次运行会产生**另一批结果**，不能充作本次记录。完整输入、参考标签、窗口、逐项实际请求、原始响应、校验结果、对照表和文件哈希仅位于 Git 忽略的 `.local_data/reviews/sec-evidence-auditor-crossco-2026-10-27-001/`。可运行其中的 `summarize_run.py`，仅从保存文件重算 `comparison.json`、`comparison.md` 和 `statistics.json`，不调用模型。

模型错误放行涉及**年份、客户数量、产品对象和金额单位**各一条。尤其有的中文理由重复了英文窗口中的正确年份或单位，却仍把改错后的主张判为支持。一条原本有直接证据的主张，模型返回的英文摘录不是对应窗口的原文，确定性摘录校验将其拒绝；其原始响应保留，未计入已接受判定。另四条非支持主张被判为 `contradicted`，未发现该批次对已接受的直接支持主张作语义误拒。这里的“支持/错误”均相对于**冻结的代理参考判定**，仍待人工复核。

这次失败分别属于语义判断和引文出处/结构校验层。摘录确实出现在窗口中，只能证明文字来源，不能证明它支持结论；通过结构校验不能代替事实审阅。若后续发现参考标签有歧义，应另写更正建议并保留本次原始标签和统计，不能静默改写。

## 局限与产品状态

本次只比较构造诊断集与代理预标注；它比旧 NVDA 八项覆盖更多公司和 filing，但仍不是用户场景准确率或可靠性提升证明。各公司仅两个窗口，同一窗口的正反主张相关；模型随机性与单次运行影响未排除。人工确认状态仍为**待用户复核**。审计器仍是独立离线实验，没有接入网页或默认回答流程，也不自动修订答案。

本轮 SEC、Alpha Vantage 和模型下载请求均为 0；本机 Ollama 调用为 16。未修改审计业务代码、提示词、Schema、校验规则、模型或冻结旧诊断集。Git 只保存方法和汇总，不保存真实 SEC 窗口、构造主张、原始响应或本地模型文件。
